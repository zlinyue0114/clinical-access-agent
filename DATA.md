# Data

All data in this project is synthetic.

- Patients, practitioners and care teams are generated by a seeded generator in
  `src/clinical_access_agent/data/`. The same seed always yields the same dataset.
- Imaging findings and report text are generated from templates in this repository.
- Ground-truth follow-up labels are computed from the structured findings.

No real patient data from any hospital or institution is used, stored or derived
from at any point. Contributions containing real patient data will be rejected and
removed.
